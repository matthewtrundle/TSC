Fax won’t open? Here’s the fix.

The Surgery Center at Plano Dermatology · Front Office Guide

Sometimes a fax arrives looking “corrupted” and won’t open. The fax is fine — it just arrived with the wrong label. This fixes it in about ten seconds. Nothing is ever deleted or changed.

1

Save the fax to this computer

In Gmail or Google Drive, click the download arrow (↓) on the fax. It lands in the Downloads folder automatically.

2

Double-click “Fix Fax” on the Desktop

A small text window will open by itself.

That window is normal — it’s the tool working. You don’t need to type anything.

3

The readable fax opens on its own

After a moment, the fixed fax pops up in Preview — read it or print it as usual. When you’re done, press Return to close the text window.

4

Need it as a PDF for the chart?

In Preview, click File → Export as PDF, then save. Done.

If it says “No broken fax files found”: that fax has a different problem — set it aside and let the office manager or Dr. Modi know.
Good to know: the tool only makes a readable copy — the original fax always stays exactly as it arrived, and everything happens on this computer.
